# CrossFit Root · WOD 플래너

매일 WOD·코어/스트랭스·스트레치를 짜서 네이버 카페에 올리는 시간을 15분 이내로 줄이는 PC용 도구입니다.
설치 없이 `index.html` 하나를 브라우저(Chrome / Edge)로 열면 바로 사용할 수 있습니다.

## 사용 방법

- **로컬:** `index.html`을 내려받아 더블클릭
- **GitHub Pages:** 저장소 Settings → Pages → Branch `main` / `(root)` 선택 후, 발급된 주소로 접속

## 화면

| 화면 | 하는 일 |
|---|---|
| **만들기** | 최근 기록 기반 부위/패턴·WOD 형식 추천 → 동작 선택 → RX/중급/초급 자동 스케일링, 장비 부족 경고, 코어/스트랭스·스트레치 제안 → 카페 글 복사 · 저장 |
| **달력** | 날짜별 프로그램, 타임별 참석 인원 + 메모, 부위별 마지막 수행일, 타임별 최대·평균 인원 |
| **설정** | 박스 이름, 동작 목록(패턴·장비·단계별 무게/대체 동작), 장비 수량, 최대 인원, 추천 기간, 백업 내보내기/불러오기 |

## 데이터 저장

- 모든 데이터는 **각자 브라우저(localStorage)에만** 저장됩니다. 서버·로그인이 없습니다.
- 같은 링크를 열어도 다른 사람에게는 빈 상태로 보입니다. 기록을 옮기거나 공유하려면 **설정 → 백업 내보내기(JSON)** 파일을 전달해 **백업 불러오기**로 가져오면 됩니다.
- 브라우저 데이터를 지우면 기록이 사라지므로 주기적으로 백업을 내보내 두세요.

## 장비 경고 계산

- **개인 점유 장비**(바벨·덤벨·박스 등): WOD 내내 1인 1개 → 최대 인원만큼 필요
- **공유 장비**(로프·로잉·바이크 등): 최대 인원 × (그 장비 동작 수 ÷ 전체 동작 수) × 형식별 보정값
- 예: EMOM 4동작 중 로프 1동작 → 15명 × 1/4 ≈ 4명 필요 > 로프 2개 → 경고 + 대체 동작 안내 문구
- 수량이 비어 있는 장비는 검사하지 않으니 설정에서 입력해 주세요.
