# CrossFit Root · WOD 플래너

매일 WOD·코어/스트랭스·스트레치를 짜서 네이버 카페에 올리는 시간을 15분 이내로 줄이는 PC용 도구입니다.
설치 없이 `index.html` 하나를 브라우저(Chrome / Edge)로 열면 바로 사용할 수 있습니다.

## 사용 방법

- **로컬:** `index.html`을 내려받아 더블클릭
- **GitHub Pages:** 저장소 Settings → Pages → Branch `main` / `(root)` 선택 후, 발급된 주소로 접속

## 화면

| 화면 | 하는 일 |
|---|---|
| **만들기** | 최근 기록 기반 부위/패턴·WOD 형식 추천 → 동작 선택 → RX/중급/초급 자동 스케일링, 장비 부족 경고, 코어/스트랭스·스트레치 제안 → 카페 글 복사 · 저장 |
| **달력** | 날짜별 프로그램, 타임별 참석 인원 + 메모, 부위별 마지막 수행일, 타임별 최대·평균 인원 |
| **설정** | 박스 이름, 동작 목록(패턴·장비·단계별 무게/대체 동작), 장비 수량, 최대 인원, 추천 기간, 백업 내보내기/불러오기 |

## 데이터 저장 방식

어디서 여느냐에 따라 저장 방식이 자동으로 정해집니다.

| 여는 곳 | 저장 위치 | 권한 |
|---|---|---|
| **Vercel** (`api/data.js` 동작 + Redis 연결) | 서버 — 모두 같은 데이터를 봄 | **코치**(비밀번호 로그인): WOD 작성·설정·메모 / **회원**(로그인 없음): 달력 보기 + 타임별 인원수만 입력 |
| GitHub Pages · 파일 직접 열기 | 각자 브라우저(localStorage) | 여는 사람이 모두 편집 가능, 다른 사람과 공유 안 됨 |

회원이 바꿀 수 있는 것은 서버에서도 타임별 인원수(0~200)로 제한합니다. 메모·프로그램·설정 변경은 코치 비밀번호가 없으면 거부됩니다.

### Vercel 서버 저장 설정 (처음 한 번)

1. Vercel 프로젝트 → **Storage** → **Upstash for Redis** (Marketplace) 생성 후 이 프로젝트에 **Connect**
   → `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 자동 추가됩니다.
2. Vercel 프로젝트 → **Settings → Environment Variables** → `COACH_PASSWORD` 에 코치 비밀번호 입력
3. **Deployments** → 최신 배포 **Redeploy** (환경변수 반영)
4. 사이트 오른쪽 위 **코치 로그인** → 비밀번호 입력

브라우저에 있던 기존 데이터는 **설정 → 백업 내보내기** 후, 코치 로그인 상태에서 **백업 불러오기**로 서버에 올릴 수 있습니다. 서버 데이터도 가끔 백업을 내보내 두세요.

## 장비 경고 계산

- **개인 점유 장비**(바벨·덤벨·박스 등): WOD 내내 1인 1개 → 최대 인원만큼 필요
- **공유 장비**(로프·로잉·바이크 등): 최대 인원 × (그 장비 동작 수 ÷ 전체 동작 수) × 형식별 보정값
- 예: EMOM 4동작 중 로프 1동작 → 15명 × 1/4 ≈ 4명 필요 > 로프 2개 → 경고 + 대체 동작 안내 문구
- 수량이 비어 있는 장비는 검사하지 않으니 설정에서 입력해 주세요.
